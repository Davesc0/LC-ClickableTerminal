# Clickable Terminal

Makes the terminal interactable with a mouse or a controller.  
The pages are drawn over the game's own, not replaced.  
Pages of other mods are pulled in too, under one MODS page.  
You can still type every command as usual.

It changes a lot, so the details are in the [Wiki](https://thunderstore.io/c/lethal-company/p/Davesco/ClickableTerminal/wiki/), one page for every part of the terminal.

I tried to cover all the vanilla menus and as many mods as I could, but I can't test everything alone.  
If something breaks or looks off with another mod, tell me on [GitHub](https://github.com/Davesc0/LC-ClickableTerminal/issues).

Every app built on Interactive Terminal API should work with the mouse and the controller, including back and menu.
They open in a window over the page you opened them from (AppsInWindow), or full screen if you turn that off.
Tested with:
- Lategame Upgrades
- Extend Deadline
- Weather Probe
- Revive
- MergeScrap
- Ship Inventory
